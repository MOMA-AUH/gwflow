gwflow v0.2.2 uses the US spelling `canceled` in Task status output and workflow explanations.

### Highlights

- Show `canceled` consistently in the Task status tree, target details, and explanation reasons.
- Filter canceled work with `gwf status --status canceled`. Help, suggested values, and shell completion use the same spelling.
- Preserve compatibility with gwf's internal states and existing status filters. The original gwf output formats retain their existing wording.

The verified setup is Python 3.12, gwf 2.1.1, and the local backend. The release workflow built and tested the Conda artifact, published it to the [MOMA-AUH channel](https://anaconda.org/MOMA-AUH/gwflow), then installed the published package and passed the cleanup and Reuse check. See the [README](https://github.com/MOMA-AUH/gwflow/blob/v0.2.2/README.md) for setup and examples.
