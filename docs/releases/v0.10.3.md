# gwflow v0.10.3 — withdrawn

On 2026-11-09, v0.10.3 was accidentally assigned to the gwf 3 integration release. The intended version is [v0.11.0](v0.11.0.md), freshly packaged and qualified from source commit `db93faec466c96f9b50b4933c3c287d095abb242`. Use the replacement release's setup and deployment guidance.

After the replacement's package and GitHub attachments were verified and the replacement release was published, Anaconda version `MOMA-AUH/gwflow/0.10.3`, the mistaken GitHub release, and tag `v0.10.3` were removed. The [guarded withdrawal run](https://github.com/MOMA-AUH/gwflow/actions/runs/42654355424) verified the replacement before deleting only the mistaken Anaconda version. Final checks on that date found v0.11.0 as the latest GitHub and Anaconda release, present in channel repodata with the verified package SHA256; v0.10.3 was absent from inventory and repodata, and its version API, distribution API, package download, GitHub release, and tag returned HTTP 404. See the [correction evidence](../validation/release-version-correction-0.11.0.json). Existing installations and cached copies are unaffected.

The withdrawn publication used source commit `5d5a849ee1068bd5f64bd0584f0f75d4b81bb5bd` and artifact `gwflow-0.10.3-py_0.conda`, SHA256 `00f6a98a03b1df0437ab79c05c732b3a2a0d0444b5ee1291f9ebe5f7e6d11208`. Its historical [master CI](https://github.com/MOMA-AUH/gwflow/actions/runs/42633147879) and [publication run](https://github.com/MOMA-AUH/gwflow/actions/runs/42637248139) describe that withdrawn package, not the replacement's validation. The withdrawn validation archive had SHA256 `b05a1f3282209b51d96b5bafe4c0f7ba08460699eb71a90a7f04b4b843cc2d3f`. Original release metadata and attachments were preserved locally before removal.
