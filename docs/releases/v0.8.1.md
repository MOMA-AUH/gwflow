gwflow v0.8.1 improves keyboard navigation in the interactive status browser and fixes historical log layout and log-view cleanup.

### Highlights

- Use `j` and `k` alongside the arrow keys to navigate groups, Tasks, jobs, history, state filters, log streams, and scrollable details. In logs, `k` pauses live following, like Up. Search fields still accept these letters as text.
- Historical job details keep the Logs panel close to the Job panel across narrow and large terminals.
- Closing a log view safely handles a pending refresh callback. This prevents a crash when a callback runs after the view closes.
- The README provides a shorter installation guide, runnable quickstart, and links to detailed operating guidance.

### Compatibility and deployment

This remains a pre-1.0 release. The [compatibility guidance](https://github.com/MOMA-AUH/gwflow/blob/v0.8.1/docs/reference.md#compatibility) continues to apply. Before an upgrade, finish or cancel affected jobs and confirm that every computation and lifecycle job is inactive. A cancellation request alone does not establish inactivity.

The deployment profile remains Linux and Bash with Python 3.12, gwf 2.1.1, and deployment-provided Apptainer 1.5.4 for containers. Automated checks use local workers, real containers, and controlled Slurm commands. Live production-cluster checks were not rerun for this release.
