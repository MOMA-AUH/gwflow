gwflow v0.2.1 makes `gwf status` easier to scan in workflows that use Tasks. Tasks appear before jobs finish, with their targets nested underneath when work is submitted, running, failed, or cancelled.

### Highlights

- Show active targets under their Task, with color and ASCII symbols for each state. Reusable Tasks stay compact in the default view.
- Use `gwf status --details` to expand every Task, including reusable Tasks whose inner targets were omitted by Reuse.
- Use `gwf status --format default` for gwf's original flat target view. Existing status filters, summary and grouped formats, and plain gwf workflows remain supported.

The verified setup is Python 3.12, gwf 2.1.1, and the local backend. The release workflow built and tested the Conda artifact, published it to the [MOMA-AUH channel](https://anaconda.org/MOMA-AUH/gwflow), then installed the published package and passed the cleanup and Reuse check. See the [README](https://github.com/MOMA-AUH/gwflow/blob/v0.2.1/README.md) for setup and examples.
