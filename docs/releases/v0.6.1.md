gwflow v0.6.1 makes Task status reports easier to scan by removing the repeated `Task` prefix from status rows, and polishes the installation and quickstart wording.

### Highlights

- Status rows begin directly with the Task name in selected-Task views such as `gwflow status '*'` and in `gwflow status --details`. This also applies to the stacked layout on narrow terminals. Tabular output retains its `Task` column heading, and computation and lifecycle jobs remain nested beneath their Task.
- Compact, detailed, colored, plain, and redirected status views preserve complete names, Task states, completed-job counts, and diagnostics. Regression coverage includes lifecycle transitions, input changes, cleanup and Reuse, and container-image changes.
- The README simplifies the Conda installation command, letting the package requirements select the supported Python version, and uses clearer task terminology throughout the quickstart.

Status-row text has changed: scripts that parse it should match the Task name directly rather than expect a `Task ` prefix. The existing [pre-1.0 compatibility and storage guidance](https://github.com/MOMA-AUH/gwflow/blob/v0.6.1/docs/reference.md#compatibility) continues to apply.

The verified setup is Linux and Bash with Python 3.12, gwf 2.1.1, and deployment-provided Apptainer 1.5.4. Python and Conda packages require Rich `>=15.0.0,<16`. Registry images require a shared cache visible at the same path on frontend and compute nodes with matching CPU architectures.

Release preparation [CI](https://github.com/MOMA-AUH/gwflow/actions/runs/38394033101) passed all 420 installed-package tests with real Apptainer fixtures, 14 local container acceptance tests, and the Conda artifact suite (376 passed, 44 expected skips) plus the packaged-example cleanup and Reuse smoke test.

The [release workflow](https://github.com/MOMA-AUH/gwflow/actions/runs/38396932685) built and tested the tagged Conda artifact, published it to the [MOMA-AUH channel](https://anaconda.org/MOMA-AUH/gwflow), then installed the published package in a fresh environment and passed the cleanup and Reuse check.

See the [README](https://github.com/MOMA-AUH/gwflow/blob/v0.6.1/README.md) for installation and the runnable quickstart, and the [reference](https://github.com/MOMA-AUH/gwflow/blob/v0.6.1/docs/reference.md) for detailed usage. The [validation guide](https://github.com/MOMA-AUH/gwflow/blob/v0.6.1/docs/validation/README.md), [registry acceptance record](https://github.com/MOMA-AUH/gwflow/blob/v0.6.1/docs/validation/registry-images/acceptance.md), and [container validation record](https://github.com/MOMA-AUH/gwflow/blob/v0.6.1/docs/validation/containers/acceptance.md) preserve earlier local, Slurm, and BeeGFS observations; live Slurm checks were not rerun for this release.
