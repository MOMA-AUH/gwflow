This is the first release of gwflow. It adds reusable **Tasks** to gwf workflows: group ordinary gwf targets, declare their external inputs and retained outputs, and reuse a completed Task after removing its internal intermediate files.

### Highlights

- Define Tasks in Python and register named instances in a workflow with `Task` and `Workflow`.
- Validate Task boundaries before submission and preserve dependencies between Tasks, so downstream work waits for the entire producing Task.
- Preview whole-workflow work with `gwf run --dry-run`, rerun with `--force`, retry failed targets, and see reused Tasks in `gwf status`.
- Keep completion records under `.gwf/` so cleaned-up Tasks can be reused on later runs.

The verified setup is Python 3.12, gwf 2.1.1, and the local backend. Use whole-workflow `gwf run`; target selectors, `--group`, and `--no-deps` are unsupported. See the [README](https://github.com/MOMA-AUH/gwflow/blob/v0.1.0/README.md) for a runnable example and setup instructions.
